# GRAND MOTORS SELECT

A modern, premium automotive website built for **GRAND MOTORS SELECT** — a concept for a boutique premium car dealership and detailing studio.

The project focuses on a refined visual identity, smooth user experience, responsive layouts and a modular React architecture.

## Live Demo

[Visit the live website](https://grand-motors-select.vercel.app)

## About the Project

GRAND MOTORS SELECT is designed around a minimal, dark and elegant aesthetic with subtle gold accents.

The website combines two main areas:

- Premium used car dealership
- Professional automotive detailing services

The goal was to create a digital experience that feels closer to a premium automotive brand than a typical used-car dealership website.

## Features

- Responsive design for desktop, tablet and mobile
- Custom premium automotive visual identity
- Dedicated detailing page
- Before / After detailing presentation
- Interactive service cards
- Mobile navigation with scroll locking
- Reusable UI components
- React Router based navigation
- Responsive typography using CSS `clamp()`
- Smooth hover and transition effects
- Custom legal pages
- Vercel deployment with automatic deployments from GitHub
- Client-side routing configured for Vercel
